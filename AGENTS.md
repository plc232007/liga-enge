# Regras do projeto

- Escreva commits simples, curtos e em português, descrevendo a alteração.
- Não adicione `Co-authored-by`, outros trailers de coautoria ou atribuições a assistentes nas mensagens de commit.
- Preserve alterações existentes e nunca envie `.env`, credenciais, bancos de dados ou backups ao Git.
- Execute `npm run check` antes de enviar alterações de código.
